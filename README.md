# obix-compiler-emit

> Previous name: `@obinexusltd/obix-compiler-emit` — OBIX packages are named without an npm scope since decision D-102 (2026-09-29); the package, its version and its exports are unchanged.

**The OBIX compiler: `.obix` → canonical DOP IR → ES6.**

```bash
npm install obix-compiler-emit
```

Installing this package installs accessibility analysis with it.

## API

```ts
import { compile, compileFile } from "obix-compiler-emit";

const { ok, ir, code, a11y, diagnostics } = compile(source, { path: "Timer.obix" });
```

## Pipeline

```
source
  → scanSections            (obix-compiler-legacy-parser)
  → parseTemplate/Script    (obix-compiler-legacy-parser)
  → validateObixAST         (obix-core-spec — the parser seal, Problem 7)
  → analyzeTemplate         (obix-compiler-legacy-template)
  → semantic checks         (unknown binding refs / unknown actions)
  → analyzeA11y             (obix-compiler-a11y — BEFORE emit, blocks on error)
  → createScopeToken + scopeCss   (obix-core-spec + obix-compiler-styles — one token, Problem 10)
  → buildIR                 (canonical DOP IR — DATA FIRST, nothing past here adds logic)
  → emitModule              (ES6; verbatim <script>, one definition of every action)
```

## No `--no-a11y` (Problem 5)

`analyzeA11y` runs unconditionally. `hasBlockingA11yError` → `compile()` returns
`ok: false` with no `code`. There is no option, flag or env var that skips it.
It is pinned by `tests/compiler/corpus.test.mjs` (11 invalid components refused with their codes, and six bypass spellings ignored) and by
`tests/cli/obixc.test.mjs` (`--no-a11y` is a usage error).

## Emit modes (Problem 6)

`"linked"` (default) / `"bare"` are implemented for Level 0. `"inline"` /
`"shared-inline"` throw `UnsupportedFeatureError` (Level 1) — they do not
silently degrade — and so does any value outside the union (it used to be emitted as `linked` under a header that named it).

## Reproducible output

The CSS scope token is a hash of the component name and its path. `compileFile` (and so `obixc`) uses the path **relative to the working
directory** with `/` separators (`componentPath`), so `Timer.obix`, `./Timer.obix` and an absolute path emit the same bytes, in any checkout
location, when the project is compiled from its root. `compile(source, { path })` hashes exactly the path it is given.

## Diagnostics

A missing `<template>` or `<script>` is `OBIX-P001` / `OBIX-P002` (with the structural `OBIX-S005`). Parse errors are `P0xx`, semantic errors
`S0xx`, accessibility `A0xx`; only errors block emission. `tests/corpus/obix/{valid,invalid,warnings}` is the corpus behind them.

## Dependency role

`obix-core-spec`, `obix-core-ir`, `obix-compiler-legacy-parser`, `obix-compiler-legacy-template`, `obix-compiler-styles`,
`obix-compiler-a11y`, `obix-compiler-validator`. Consumed by `obix-cli-compile` and
`obix-compiler-language-server`. Never depends on any adapter, the runtime, or `obix-fixture-timer`.

## Level 0 status

✅ props, state, actions, derived, `every` effect, text/attr/bool/ARIA
interpolation, `on:` events, single-element `obix:if`, scoped CSS, native-mount
IR. Deferred: loops, slots, composition, hydration, SCSS, async.
